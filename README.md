## 🎯 অ্যাপটি কী করে

GitHub-এর ওয়েবসাইটে ফোন থেকে ফাইল আপলোড করতে গেলে একটা একটা করে ফাইল দিতে হয়, ফোল্ডার দেওয়া যায় না। Termux ব্যবহার করলে `git` দিয়ে পুরো ফোল্ডার পাঠানো যায়, কিন্তু সেটার জন্য কমান্ড জানতে হয়।

এই অ্যাপ সেই কাজটাই করে:

1. আপনি **টোকেন** দেন, **রিপো** বাছাই করেন, **ফোল্ডার** দেখিয়ে দেন।
2. **Push** চাপলে পুরো ফোল্ডার, ভেতরের সব সাবফোল্ডারসহ, **একটা কমিটে** GitHub-এ চলে যায়।
3. GitHub-এ ঠিক ফোনের ফোল্ডারের মতো সাজানো অবস্থায় দেখা যায়।

| `.github/workflows` বাদ দেওয়ার সুইচ | টোকেনে `workflow` অনুমতি না থাকলে এটা চালু রাখলে আপলোড আটকায় না |
| সাবফোল্ডারে আপলোড | রিপোর রুটে না গিয়ে ভেতরের কোনো ফোল্ডারে পাঠানো যায় |

### 🔔 ব্যাকগ্রাউন্ড আপলোড
- Push চাপার পর **অ্যাপ বন্ধ করলেও বা ফোন লক হলেও** আপলোড চলতে থাকে।
- চলার সময় নোটিফিকেশনে **প্রগ্রেস বার** আর **বাতিল** বাটন।
- শেষে ফলাফলের নোটিফিকেশন, সফল হলে **GitHub-এ দেখুন** বাটনসহ।
- Android 13+ এ প্রথমবার নোটিফিকেশনের অনুমতি চাইবে। না দিলেও আপলোড হয়, শুধু নোটিফিকেশন দেখা যায় না।

### 👥 একাধিক অ্যাকাউন্ট
- একাধিক টোকেন সেভ করা যায়, উপরের `@নাম` চিপ ট্যাপ করলেই অ্যাকাউন্ট বদলে যায়।
- চিপের `×` চাপলে শুধু ওই টোকেন ফোন থেকে মুছে যায়।

### 🔨 বিল্ড ট্র্যাকার
- GitHub Actions-এর বিল্ডের অবস্থা অ্যাপের ভেতরেই দেখা যায় (অপেক্ষায় / চলছে / সফল / ব্যর্থ)।
- সফল বিল্ডের APK সরাসরি নামিয়ে ইনস্টল করা যায়।
- পুরনো বিল্ড ও APK মুছে জায়গা পরিষ্কার করা যায়।

### 🎨 চেহারা
- পরিষ্কার, আইকনসহ UI। সম্পূর্ণ ধাপ নিজে গুটিয়ে যায়, নিচে স্থায়ী Push বাটন।
- **বাংলা / English**, **লাইট / ডার্ক / ফোনের মতো**।

### 🔒 লগআউট ও তথ্য মোছা
- এক ট্যাপে টোকেন ফোন থেকে মুছে ফেলা।

## 📲 ফোনে ইনস্টল করার নিয়ম (শুধু ফোন দিয়ে)

কম্পিউটার বা Android Studio লাগবে না। GitHub নিজেই অ্যাপ বিল্ড করে দেবে।

### ধাপ ১: একটি রিপো নিন
GitHub-এ একটি রিপো বানান (প্রাইভেট হলেও চলবে)।

### ধাপ ২: workflow ফাইল বসান
1. রিপোতে **Add file → Create new file** চাপুন।
2. ফাইলের নাম লিখুন: `.github/workflows/build.yml`
3. `build-apk-all-in-one.yml` ফাইলের **পুরো লেখা** কপি করে ভেতরে বসান।
4. **Commit changes** চাপুন।

> 💡 এই এক ফাইলের ভেতরেই পুরো অ্যাপের সোর্স কোড ঢোকানো আছে। প্রথম বিল্ডে সে নিজেই সব ফাইল বের করে রিপোতে বসিয়ে নেয়।

> ⚠️ ZIP ফাইল রিপোতে আপলোড করলে সেটা নিজে খুলে যায় না। তাই ZIP-এর বদলে ওপরের এক ফাইলের পদ্ধতি ব্যবহার করুন।

### ধাপ ৩: বিল্ডের জন্য অপেক্ষা
1. রিপোর **Actions** ট্যাবে যান। বিল্ড নিজে থেকে শুরু হবে।
2. সবুজ ✅ চিহ্ন এলে বিল্ড শেষ (সাধারণত ৫-১০ মিনিট)।

### ধাপ ৪: APK নামান
1. শেষ হওয়া বিল্ডে ট্যাপ করুন।
2. নিচে **Artifacts** থেকে `GitFolderUploader-debug-apk` নামান।
3. ZIP খুলে ভেতরের `app-debug.apk` ইনস্টল করুন।
4. ফোন জিজ্ঞেস করলে "অজানা সোর্স থেকে ইনস্টল"-এর অনুমতি দিন।

> প্রথমবার বিল্ড ব্যর্থ হলে Actions-এ ব্যর্থ বিল্ড খুলে লাল ❌ ধাপের লেখাটা দেখুন। সেটাই সমস্যার কারণ বলে দেবে।

## 🔑 অ্যাক্সেস টোকেন বানানো

GitHub → **Settings → Developer settings → Personal access tokens**

| টোকেনের ধরন | যা যা অনুমতি লাগবে |
|---|---|
| **Classic** (সবচেয়ে সহজ) | ✅ `repo`<br>➕ `.github/workflows` আপলোড করতে চাইলে `workflow` |
| **Fine-grained** | ✅ Repository access: নির্দিষ্ট রিপো বা সব<br>✅ **Contents: Read and write**<br>➕ workflows আপলোডে **Workflows: Read and write**<br>➕ বিল্ড ট্যাবের জন্য **Actions: Read and write** |

নতুন রিপো বানাতে চাইলে Classic-এ `repo` যথেষ্ট। Fine-grained-এ অ্যাকাউন্টস্তরের রিপো তৈরির অনুমতিও লাগে।

> 🔐 টোকেন পাসওয়ার্ডের মতো। কাউকে দেবেন না, কোথাও পোস্ট করবেন না।

## 🚀 ব্যবহারের নিয়ম

অ্যাপ খুললে উপরে ছোট হেডার (নাম, অ্যাকাউন্টের অবস্থা, ⚙️ সেটিংস), তার নিচে ট্যাব, আর চারটি ধাপ।

### ১️⃣ অ্যাকাউন্ট
1. **Access Token** ঘরে টোকেন বসান।
2. **যাচাই করুন** চাপুন। সফল হলে `@আপনারনাম সংযুক্ত` দেখাবে এবং ধাপটি গুটিয়ে যাবে।

### 2️⃣ রিপোজিটরি
- **আমার রিপোগুলো থেকে বাছাই করুন** চাপলে তালিকা আসবে। সার্চ করে ট্যাপ করুন, রিপো ও ডিফল্ট ব্রাঞ্চ নিজে বসে যাবে।
- অথবা হাতে `owner/repo` বা রিপোর লিংক লিখুন।
- **ব্রাঞ্চ** (যেমন `main`) আর **কমিট মেসেজ** দিন।

### 3️⃣ ফোল্ডার
1. **ফোল্ডার বাছাই করুন** চেপে প্রজেক্ট ফোল্ডার দেখিয়ে দিন।
2. অ্যাপ নিজে স্ক্যান করে দেখাবে: **ফাইল সংখ্যা**, **মোট সাইজ**, **বাদ পড়া বড় ফাইল**।
3. **ফাইলের তালিকা দেখুন** চাপলে কী কী যাবে দেখা যায়।

> ⚠️ **Download** বা স্টোরেজের মূল ফোল্ডার বাছাই করা যায় না (Android-এর নিয়ম)। তার ভেতরের প্রজেক্ট ফোল্ডারটি বাছাই করুন।

### 4️⃣ Push
- স্ক্রিনের নিচের **Push to GitHub** বাটন চাপুন। টোকেন, রিপো ও ফোল্ডার ঠিক থাকলেই বাটন চালু হয়।
- প্রগ্রেস বার ও টার্মিনাল-স্টাইলের লগ দেখা যাবে (`✓` সফল, `!` সতর্কতা, `✗` ব্যর্থ)।
- শেষে **কাজ শেষ!** দেখাবে, **GitHub-এ দেখুন** বাটনে কমিট খোলে।
- চলার সময় **বাতিল করুন** চাপা যায়। বাতিল করলে কমিট তৈরি হয় না, রিপো আগের মতোই থাকে।

## 🔨 বিল্ড ও APK ট্যাব

আপলোড ট্যাবের পাশে দ্বিতীয় ট্যাব। রিপো ও টোকেন দেওয়া থাকলে কাজ করে (টোকেনে **Actions** অনুমতি লাগবে)।

- **বিল্ডের তালিকা:** সর্বশেষ বিল্ডগুলো, সঙ্গে অবস্থা আর কত আগে হয়েছে। কোনো বিল্ড চললে প্রতি ৮ সেকেন্ডে নিজে রিফ্রেশ হয়।
- **APK নামান ও ইনস্টল:** সফল বিল্ডের APK অ্যাপের ভেতরেই নেমে যায়, এক ট্যাপে ইনস্টল। প্রথমবার ইনস্টলের অনুমতির জন্য সেটিংস খুলতে পারে।
- **আবার চালান:** ব্যর্থ বিল্ড আবার চালু করে।
- **মুছুন / পুরনো পরিষ্কার:** GitHub থেকে বিল্ড ও তার APK মুছে। "পুরনো পরিষ্কার" সবচেয়ে নতুন ৩টি রেখে বাকি সম্পূর্ণ বিল্ডগুলো মুছে।
- **ডাউনলোড করা APK:** ফোনে নামানো APK আলাদা তালিকায়, ইনস্টল বা মোছা যায়।

---

## 🔄 অ্যাপ আপডেট করার নিয়ম

1. রিপোতে `.github/workflows/build.yml` খুলে ✏️ (Edit) চাপুন।
2. ভেতরের **সব লেখা মুছে** নতুন `build-apk-all-in-one.yml`-এর লেখা বসিয়ে কমিট করুন।
3. Actions-এ বিল্ড শেষ হলে অ্যাপের **বিল্ড ও APK** ট্যাব থেকে নতুন APK নামিয়ে ইনস্টল করুন।

> **স্থায়ী সাইনিং কী:** প্রথম বিল্ডে একটি `app/debug.keystore` তৈরি হয়ে রিপোতে সেভ হয়। এরপর থেকে সব APK একই কী দিয়ে সই হয়, তাই নতুন APK আগেরটার উপর আপডেট হিসেবে বসে, আগেরটা মুছতে হয় না। (পুরনো কোনো সংস্করণ, যেটা এই কী ছাড়া তৈরি, থাকলে একবারই আনইনস্টল করে নতুনটা বসাতে হবে।)

## 🧠 ভেতরে কীভাবে কাজ করে

অ্যাপ `git` চালায় না। সরাসরি **GitHub Git Data API** ব্যবহার করে:

```
 ফোনের ফোল্ডার
      │  (Storage Access Framework)
      ▼
 ফাইল তালিকা তৈরি ── বাদ দেওয়ার নিয়ম প্রয়োগ
      │
      ▼
 প্রতিটি ফাইল ──▶ POST /git/blobs      (base64)
      │
      ▼
 সব blob জুড়ে ──▶ POST /git/trees     (আগের ট্রির উপর ভিত্তি করে)
      │
      ▼
 ট্রি অপরিবর্তিত? ──হ্যাঁ──▶ কমিট নেই, "কিছু বদলায়নি"
      │ না
      ▼
 POST /git/commits ──▶ PATCH /git/refs/heads/<ব্রাঞ্চ>
```

- **একটাই কমিট:** সব ফাইল একসঙ্গে ট্রিতে যোগ হয়, তাই ইতিহাসে একটাই এন্ট্রি।
- **সুরক্ষা:** মাঝপথে বন্ধ বা বাতিল হলে রিপো অপরিবর্তিত থাকে, কারণ ব্রাঞ্চ শেষ ধাপে একবারই সরে।
- **রেট লিমিট সামলানো:** অনুরোধের মাঝে বিরতি (প্রায় ০.৮৫ সেকেন্ড), একসঙ্গে সর্বোচ্চ ৩টি ছোট ফাইল, ২ MB-র বেশি ফাইল একটা একটা করে। রেট লিমিটে আটকালে অপেক্ষা করে আবার চেষ্টা করে।
- **ব্যাকগ্রাউন্ড:** আপলোড একটি ফোরগ্রাউন্ড সার্ভিসে চলে (ধরন: `dataSync`)।

## 🛡️ নিরাপত্তা ও গোপনীয়তা

- **টোকেন** `EncryptedSharedPreferences`-এ (Android Keystore-এর AES-256) সংরক্ষিত হয়। অ্যাপের বাইরে কোথাও পাঠানো হয় না।
- অ্যাপ শুধু `api.github.com`-এর সঙ্গে কথা বলে। কোনো অ্যানালিটিক্স বা তৃতীয় পক্ষের সার্ভার নেই।
- `allowBackup=false`, তাই ব্যাকআপের মাধ্যমে টোকেন অন্য জায়গায় যায় না।
- ফোল্ডারের অনুমতি **শুধু পড়ার** (read-only)। অ্যাপ আপনার ফাইল বদলায় না বা মোছে না।
- আপনার GitHub অ্যাকাউন্টের কোনো সেটিং বদলায় না। শুধু বেছে নেওয়া রিপোর বেছে নেওয়া ব্রাঞ্চে কমিট করে।
- লগআউট বা "সব তথ্য মুছুন" করলে টোকেন ও সংরক্ষিত তথ্য ফোন থেকে মুছে যায়। GitHub-এ কিছু বদলায় না।

> একই টোকেন দিয়ে এভাবে আপলোড করলে GitHub অ্যাকাউন্টে সমস্যা হওয়ার কথা নয়, এটা সাধারণ API ব্যবহার। তবে অল্প সময়ে অস্বাভাবিক বেশি অনুরোধ করলে GitHub সাময়িক রেট লিমিট দিতে পারে, অ্যাপ তখন নিজে থেমে অপেক্ষা করে।

## 🧰 সমস্যা হলে কী করবেন

| লক্ষণ | কারণ ও সমাধান |
|---|---|
| **401 / Bad credentials** | টোকেন ভুল বা মেয়াদ শেষ। নতুন টোকেন বানান |
| **403 / Resource not accessible** | টোকেনে `repo` (Classic) বা Contents: Read and write (Fine-grained) নেই |
| **404 Not Found** | রিপোর নাম ভুল, অথবা টোকেন ওই প্রাইভেট রিপো দেখতে পায় না |
| `.github/workflows` আপলোডে ব্যর্থ | টোকেনে `workflow` অনুমতি নেই। অনুমতি দিন, অথবা সেটিংসে "workflows ফোল্ডার বাদ দিন" চালু করুন |
| রিপো তৈরি হচ্ছে না | টোকেনে রিপো তৈরির অনুমতি নেই |
| রেট লিমিট সতর্কতা | কিছু না করে অপেক্ষা করুন, অ্যাপ নিজে আবার চেষ্টা করবে |
| ব্রাঞ্চ পাওয়া যায়নি | ব্রাঞ্চের নাম মিলিয়ে দেখুন (`main` নাকি `master`) |
| বিল্ড ট্যাবে "Actions অনুমতি" ত্রুটি | টোকেনে Actions: Read and write দিন |
| APK ইনস্টল হচ্ছে না | সেটিংস থেকে এই অ্যাপকে "অজানা অ্যাপ ইনস্টল"-এর অনুমতি দিন |
| নতুন APK আপডেট না হয়ে ইনস্টল ব্যর্থ | আগের APK ভিন্ন সাইনিং কী দিয়ে তৈরি। একবার আনইনস্টল করে নতুনটা বসান |
| Actions-এ বিল্ড ব্যর্থ | ব্যর্থ ধাপের লাল লেখাটা দেখুন, দরকারে সেটা পাঠান |
